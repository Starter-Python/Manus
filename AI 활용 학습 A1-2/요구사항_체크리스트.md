# 과제 요구사항 체크리스트

이 문서는 제공된 **A1-2 과제 안내문**을 기준으로 작성한 제출 전 검증표입니다. 상태의 `구현 완료`는 코드와 문서에 해당 기능이 설계·구현되어 있음을 뜻합니다. 2026-08-13에 문법 검사, 단위 테스트 6건, 잘못된 날짜 입력, 실제 LLM 호출과 결과 파일 생성을 검증했습니다. Kakao REST API 키는 실행 환경에 제공되지 않아, 과제에서 요구한 **장소 검색 실패/키 미설정 시 계속 진행** 경로로 검증했습니다.

## 1. 최종 결과물

| 요구사항 | 구현 위치 | 확인 방법 | 상태 |
|---|---|---|---|

| 원본 JSON 결과 파일 | `write_results()` | `results/YYYY-MM-DD_travel_data.json` 확인 | 구현 완료 |
| 최종 Markdown 리포트 | `write_results()` | `results/YYYY-MM-DD_travel_plan.md` 확인 | 구현 완료 |
